# 中文发布文案

## 标题

ToyBox 简体中文汉化修订（对应 1.7.34）

## 简介

ToyBox 1.7.34 的简体中文词表修订。统一职业、剧情状态与重置加点等术语，修正旧译并补译灵能设置、蓝图补丁工具和角色编辑界面。需要原版 ToyBox。

## 正文

这是《战锤 40,000：行商浪人》ToyBox 的简体中文汉化附加包，针对 **ToyBox 1.7.34** 制作，汉化包版本为 **1.0**。

原词表中有一些功能名称和说明不够准确，部分新增界面也没有对应译文。本修订保留原词表所有 680 个键，修订 345 条已有译文，并补充 276 个键，共 956 条。新增键包含新的短语、枚举显示名称及富文本匹配变体。

**主要改进**

- Archetypes 统一为“职业”，Etudes 统一为“剧情状态”。
- Respec 统一为“重置加点”，Search 'n Pick 统一为“搜索与添加”。
- 修正把《行商浪人》误写为“正义之怒”等旧译问题。
- 与本地官方汉化对齐社交、弹道技能、障壁恶化、信念、派系、技能及虚空舰相关术语。
- 补译灵能异象设置、蓝图补丁管理器、角色编辑器和新增设置说明。
- 补充 ToyBox 1.7.34 富文本产生的精确匹配键。

**依赖与安装**

先安装 [ToyBox for Rogue Trader](https://www.nexusmods.com/warhammer40kroguetrader/mods/1)，确认版本为 1.7.34，并关闭游戏。

找到现有 `0ToyBox0` 目录，备份 `Localization\zh-CN.json`，将本包内同名文件覆盖到该位置。默认目录：

```text
%USERPROFILE%\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\UnityModManager\0ToyBox0
```

启动游戏，在 ToyBox 设置中选择简体中文（`zh-CN`）。本包只有词表，没有原模组 DLL，请手动覆盖到已安装模组目录。

恢复旧译时，关闭游戏并复制回自己的备份。ToyBox 更新可能覆盖汉化，更新后请先确认兼容性再重新安装本包。

**已知保留范围**

词表只能处理上游接入翻译接口的文本。部分写死的界面英文仍会保留，例如某些对话与角色开关、升级说明和补丁操作状态。蓝图内部名称、字段名、类型名、GUID、路径及 Unity Mod Manager 自身界面也不在本包修改范围内。品牌名、按键名与坐标轴名称按原样保留。

本修订只更改 `zh-CN.json`。游戏对象的名称和描述由游戏语言设置控制。

**测试状态**

静态词表检查通过；当前 1.0 候选包待游戏界面验收。请勿将这一状态理解为已完成全界面实机测试。
