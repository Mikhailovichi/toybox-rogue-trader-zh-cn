# ToyBox Rogue Trader Chinese Localization

Two complementary projects for ToyBox's Simplified Chinese interface in **Warhammer 40,000: Rogue Trader**. Both target **ToyBox 1.7.34** and are installed separately.

| Project | Version | What it changes | Installation |
| --- | --- | --- | --- |
| [Revised Chinese Dictionary](dictionary-localization/README.md) | 1.0 | Corrects translations, standardizes game terminology and adds Chinese interface labels and descriptions. | Replace `Localization/zh-CN.json` inside the existing `0ToyBox0` directory. |
| [Chinese Display Enhancements](display-enhancements/README.md) | 0.2 candidate | Makes supported dialogue conditions and result previews easier to read, and adds Chinese names or notes to eight internal feature entries. | Install as a separate UMM mod alongside `0ToyBox0`. |

Both projects require the original ToyBox mod. You can use them together: the display addon does not install or overwrite the dictionary. Neither package includes the original ToyBox DLL.

## Installation Guides

- **Dictionary localization:** [English](dictionary-localization/README.md) | [简体中文](dictionary-localization/README.zh-CN.md)
- **Display enhancements:** [English](display-enhancements/README.md) | [简体中文](display-enhancements/README.zh-CN.md)

Select Simplified Chinese (`zh-CN`) in ToyBox. Official game names and descriptions follow the game's own language setting. Each project's guide explains its requirements, installation, updates and limitations.
