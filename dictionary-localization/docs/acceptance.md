# 词表 2.1 验收与交接

## 当前目标与状态

目标为 **ToyBox 2.0.20 预发布版**，本机游戏 **1.6.1.514**。以官方包的中英文词表为基线，按字段 ID 沿用 216 条修订，其中 86 条补齐上游缺译。新增两项使用官方中文，合计 940 个字段，含四个空原文字段。离线重建、字段、重复键、原文、格式参数、换行和富文本校验通过。13 项词表测试通过。

2026 年 11 月 20 日已在本机随 ToyBox 2.0.20 安装词表 2.1。ToyBox 的「设置」→「列表与浏览器」显示了「允许修改所有特性的等级」及完整说明，功能搜索也能按中文标题命中。升级页的重置加点说明显示了 0／15／35 级用法。

候选包为 [`toybox-zh-cn-v2.1.zip`](../../release/toybox-zh-cn-v2.1.zip)。本机旧 `0ToyBox0` 和 `ToyBoxDisplayEnhancements` 目录都保存在游戏用户数据下的 `ModBackups/toybox-snapshot-2026-11-20/`。整套回滚时关闭游戏，先将现有两个目录移出 UMM，再把备份的两个目录复制回原位置。单独恢复官方译文时使用 2.0.20 包内同名词表。逐项审阅见 [`translation-review.json`](translation-review.json)，重建见[维护说明](maintenance.md)。

## 查看界面

以下页签可用于后续版本复查。启动游戏，将 ToyBox 与游戏设为简体中文，查看标签和说明。

1. 百宝袋／预览：出现条件、选择要求、信念变化与信念要求。
2. 蓝图补丁：标签页、管理器、基础类型／引用／集合、普通及高风险补丁提示。不要创建或应用补丁。
3. 搜索与选取：分类、数值参数、即时搜索、描述搜索及名称设置。
4. 存档：浏览信息与修改游戏 ID 的分组说明，不修改 ID。
5. 视角：区分视野角度与战争迷雾揭示范围，查看鼠标中键说明。
6. 重置加点：从 0／15／35 级的职业说明、关闭功能后的影响，不执行重置。
7. 实际排版：截断、乱码、格式参数未替换、富文本裸露或英文回退。

反馈可附页签、原文或截图。修订时更新 `revisions.json` 与审阅记录，再重建候选包。显示增强的实测样本见其[验收记录](../../display-enhancements/docs/acceptance.md)。发布资料见[发布说明](publishing.md)。
