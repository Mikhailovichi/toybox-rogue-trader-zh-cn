# 新版词表的英文范围

目标为 ToyBox **2.0.16**。词表仅覆盖新版 `Language` 中已登记的 938 个字段；英文原文不再是查找键。不能通过新增英文键翻译任意运行时文本。

## 已补齐与仍保留的内容

86 条非空原文的缺译均已补齐，主要为蓝图补丁工具，另含战争迷雾范围倍率、数值参数与不适用标签。四条空原文是能力目标限制选项的空提示，保留为空，不补写功能说明。

内部蓝图名称、GUID、类名、字段名、资源 `guid/fileid`、示例技术标识继续保留。它们用于搜索和定位，不当作漏译。游戏名称与描述由游戏语言决定。

## 未登记文本

新版 `ToyBox/Classes/Features/SettingsTab/LanguagePickerFeature.cs` 中的 `Select` 按钮直接写入 UI，未登记字段 ID，词表无法翻译。对话条件和动作的 `GetCaption()` 由游戏生成，也不等同于词表字段；其中受支持的语义由独立显示增强处理，未知类型保留原摘要。

上述源码路径以官方 `v2.0.16` 为准，常规重建无需源码。旧版 `.localize()` 精确键、颜色变体、有限枚举扩展的覆盖统计不用于新版。
