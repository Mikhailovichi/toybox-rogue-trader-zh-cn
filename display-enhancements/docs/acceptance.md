# 显示增强 0.5 验收记录

## 当前目标与状态

目标为 **ToyBox 2.0.20 预发布版**、游戏 **1.6.1.514**、显示增强 **0.5.0**。构建零警告、零错误。805 项托管格式化与 Harmony 断言、211 项真实程序集检查通过。八个特性的中英文别名继续以本机资产为依据，详见[核查记录](feature-evidence.md)。

候选包为 [`toybox-display-enhancements-v0.5.zip`](../../release/toybox-display-enhancements-v0.5.zip)，11 个文件均与构建输出核对。旧 0.3／0.4 ZIP 对应 ToyBox 2.0.16，0.1／0.2 ZIP 对应 ToyBox 1.7.34。

## 本机实测

2026 年 11 月 20 日，UMM 显示 ToyBox 2.0.20 和显示增强 0.5.0 均已启用，`GameLogFull.txt` 记录加载了 13 个显示补丁。「搜索与选取」以 GUID `3d43526266ce4243913cec04f2f9f53d` 命中 `Answer_0007`，显示回答摘录和正文。

临时只读面板调用游戏进程内已打补丁的 ToyBox 条件和动作格式化入口，使用本机真实蓝图。四种中英组合均确认说明随 ToyBox，技能、对白、物品、殖民地和特质的正式文本随游戏语言。

| 样本 | 实测显示 |
| --- | --- |
| 选项检定 | 自定义「先攻值，基础 DC 50」，预设「知识（帝国），困难」，同时覆盖简单、普通及不可能 |
| 对话历史 | `Answer_0007` 显示「此前显示过该对话」并附对白摘录 |
| 物品 | 获得「移动采矿站」× 1，扣除「Cargo_Fuselin_Full」数量 10，移除全部「日蚀协议激活密钥」。资金、比例与固定数量并列由夹具验证 |
| 殖民地特质 | 为指定殖民地「达戈努斯」添加特质「王朝编年史」 |

验收后恢复简体中文，移除临时面板，22 个存档的数量与最新写入时间均与验收前一致。实际对话选项内的长文本布局可按下方步骤复查。没有可用正式名称的条目会保留内部名，例如 `Cargo_Fuselin_Full`。剧情状态别名目前只登记「异端」，其余按实际蓝图逐条补证据。

## 已覆盖的行为

- 新版 `GeneralSettings`、六个对话格式化入口、四个 `BPHelper` 入口及三个缓存刷新入口；游戏语言后置补丁只刷新缓存，没有旧列表 getter 补丁。
- 完整条件 AND／OR、嵌套、整体与单项否定；条件数组不猜组合关系，空摘要不改变分支，未知类型保留原摘要。
- GUID 登记的“异端未在运行”与 `Story state "Heresy" is not running`；别名来源不依赖名称与内部名的差异。对白去富文本，中文 40 字、英文 120 字符截断并尽量保留完整单词；当前与历史对白范围、商人选择与招募门槛、任务目标和所属任务名均有双语断言。
- 游戏本地化的信念与检定名称、信念数值、等级要求回退、技术详情保存；格式化不执行动作、不增加条件求值、不改变分支收集。
- `Answer Selected` 和 `Answer List Shown` 的本次／此前、肯定／否定提示，以及 AND／OR 嵌套、引用缺失和技术详情；选项组按顺序引用首条有文本的回答，循环引用可结束，显示记录与选择记录保持各自含义。
- 回答与选项组的蓝图名称、完整描述、摘录与全文搜索、内部名及 GUID 搜索和简洁名称排序；完整回答遵循描述搜索开关，官方描述保留，内部名开关及四种中英组合同步刷新，关闭增强或不支持语言时恢复原显示。
- 对白、检定、对话、叙事页、对白序列与出口的浏览器显示；容器按规定顺序引用首条有效文本，不跟随检定分支或回答后续，空文本与循环引用保留回退。对白全文搜索、配置难度、隐藏检定及条件修正均有夹具覆盖。
- 本次检定成功与失败记录及其否定；队友四类状态和死亡筛选，物品与资金分支，能力／效果目标，标志解锁和值集合／闭区间。回答标记／清除与开始对话动作、标志静态／动态增量均通过已安装的 Harmony 入口验证。
- 新增夹具为动态 `GetValue()`、分支 `Select()`、可选性检查、检定结果分支和标志实时值设置失败哨兵；条件与动作计数保持不变，结果预览仍只执行一次上游遍历。
- 四种中英组合覆盖增强短句与游戏正式文本的独立语言来源。选项检定、对话历史、物品数量和资金、指定及当前殖民地均有 Harmony 夹具覆盖。
- 八个特性的官方名称和描述优先；中英文别名、内部名、GUID 搜索，当前增强语言的补充描述搜索遵循开关。
- 增强关闭、两种语言切换及重新启用时刷新缓存，名称、搜索、排序与描述恢复。不支持的 ToyBox 语言停用增强；英语区域代码启用英文增强。

## 用户界面验收

如需复查其他环境，关闭游戏并按 [README](../README.md) 将 0.5 安装到 UMM 的 `ToyBoxDisplayEnhancements` 目录。把 `display-settings.json` 从使用旧 ID 的目录迁入新版，再将旧目录移到 UMM 之外。打开界面查看预览、搜索结果和说明。

1. **加载与语言**。在 UMM 中确认 ToyBox 2.0.20 和显示增强 0.5.0 已启用，显示 13 个补丁已安装。开启 ToyBox 的「百宝袋」→「预览」中的「对话结果」和「对话条件」。分别查看 ToyBox 与游戏的全中文、全英文及两种混合设置。
2. **商人与招募**：中文显示“打开商人选择界面”和“进入自定义队友创建流程”；英文显示 `Open vendor selection` 和 `Begin custom companion creation`。招募要求显示利润因子门槛；“结果预览”／`Result preview` 与“后续可能涉及”／`Possible later results` 分层可读。
3. **剧情与对白**：单条件显示“剧情状态‘异端’未在运行”或 `Story state "Heresy" is not running`；多条件展开 AND／OR、单项与整体否定及嵌套缩进。对白引用区分本次对话与此前记录，检查英文长对白截断和分组换行；未知摘要仍可读。
4. **任务、信念与检定**：任务目标附所属任务名；信念名称、正负值与要求含义正确，出现检定使用游戏技能名称与难度。检查长文本换行、富文本和截断。
5. **八个特性**：按 [核查表](feature-evidence.md) 搜索八个 GUID 或内部名，检查名称和“汉化说明”／`Addon note`。分别使用中英文别名、内部名、GUID 搜索，开启／关闭描述搜索并比较结果；有效官方名称和描述优先，不点击增删或等级调整。
6. **技术详情**：在增强 UMM 面板切换详情，检查当前增强语言的说明、原摘要和内部标识，包括英文 Heresy 的别名来源；重启游戏后偏好仍保存。
7. **恢复**：切换 ToyBox 和游戏语言，重新查看预览和特性列表，名称、搜索、排序与描述同步更新。关闭增强或切换 ToyBox 为不支持的语言，确认原显示恢复；重新开启并切回中文或英文后增强恢复。
8. **回答条件**：查看含 `Answer Selected` 或 `Answer List Shown` 的对话提示，确认分别说明是否选过回答、是否显示过选项组，并引用正式回答。核对本次／此前、肯定／否定及技术详情中的原内部名和 GUID，只查看提示，不为测试选择回答。
9. **回答蓝图**：在蓝图浏览器搜索实际出现的 `Answer_00101` 等内部名或其 GUID，确认名称显示回答摘录、描述提供全文。用摘录中的词搜索，再开启“搜索描述”查找摘录以外的词；切换内部名显示时，名称附加原标识，排序保持简洁名称。对选项组查看代表回答，切换语言及增强开关后确认名称、搜索、排序和描述同步更新，不运行蓝图动作。
10. **对白与容器蓝图**：搜索已有 `Cue_…`、对话、叙事页、对白序列与出口，检查名称和描述是否引用同一条正式文本；搜索摘录和全文中的词，比较内部名显示、排序和语言切换。无正文条目保留原名；容器内容仅用于辨认，不代表该分支会发生。
11. **检定与常用条件**：查看已有检定蓝图，确认基础 DC 与预设难度分开、隐藏检定和条件修正说明清楚。查看对话中的检定记录、队友、物品、能力／效果、标志条件，核对成功／失败记录的否定、角色筛选、数量门槛、目标及标志解锁前提；只查看提示。
12. **新增预览**。选项检定区分预设难度与基础 DC，对话历史引用代表对白。物品与资金区分固定数量、比例和全部扣除，殖民地特质显示配置目标。用技术详情核对原摘要、内部名称及 GUID。

## 回滚与维护

本机回滚使用游戏用户数据目录下的 `ModBackups/toybox-snapshot-2026-11-20/`，包含 ToyBox 2.0.16 及其词表和显示增强 0.4.0 的两个完整目录。关闭游戏，先将 UMM 中的新版两个目录移出，再将旧版两个目录复制回原位置。构建与测试见[维护说明](maintenance.md)。
