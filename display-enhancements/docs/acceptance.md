# 显示增强 0.4 验收记录

## 当前目标与状态

目标 ToyBox **2.0.16 预发布版**、游戏 **1.6.1.514**，增强 **0.4.0**，公开名称 **ToyBox Display Enhancements**。13 个补丁通过 279 项托管格式化／Harmony 断言、81 项真实程序集检查；构建零警告、零错误。八个特性保留本机资产核查依据，中英文别名的 GUID 与内部名一致，官方文本优先，详见 [核查依据](feature-evidence.md)。

候选 ZIP：`../../release/toybox-display-enhancements-v0.4.zip`，包内 11 个文件已与源码输出逐项核对。静态与夹具验证已完成，新版游戏内加载和排版待用户安装验收。旧 0.3 ZIP 保留供 ToyBox 2.0.16 使用，0.1／0.2 ZIP 保留供 ToyBox 1.7.34 使用；旧截图不作为新版效果展示。

## 已覆盖的行为

- 新版 `GeneralSettings`、六个对话格式化入口、四个 `BPHelper` 入口及三个缓存刷新入口；游戏语言后置补丁只刷新缓存，没有旧列表 getter 补丁。
- 完整条件 AND／OR、嵌套、整体与单项否定；条件数组不猜组合关系，空摘要不改变分支，未知类型保留原摘要。
- GUID 登记的“异端未在运行”与 `Story state "Heresy" is not running`；别名来源不依赖名称与内部名的差异。对白去富文本，中文 40 字、英文 120 字符截断并尽量保留完整单词；当前与历史对白范围、商人选择与招募门槛、任务目标和所属任务名均有双语断言。
- 游戏本地化的信念与检定名称、信念数值、等级要求回退、技术详情保存；格式化不执行动作、不增加条件求值、不改变分支收集。
- 四种中英组合：增强说明跟随 ToyBox，官方任务、对白、信念与检定跟随游戏；其他游戏语言保留其有效官方文本，未知摘要保留原文。
- 八个特性的官方名称和描述优先；中英文别名、内部名、GUID 搜索，当前增强语言的补充描述搜索遵循开关。
- 增强关闭、两种语言切换及重新启用时刷新缓存，名称、搜索、排序与描述恢复。不支持的 ToyBox 语言停用增强；英语区域代码启用英文增强。

## 用户界面验收

关闭游戏，按 [README](../README.md) 使用 Modfinder 拖入 ZIP 或手动解压，将 0.4 安装到游戏随附 UMM 的 `ToyBoxDisplayEnhancements` 目录。若有旧 `ToyBoxChineseDisplayEnhancements`，将其中的 `display-settings.json` 复制到新目录后移除旧目录，备份置于 UMM 之外；不要同时加载两套增强。包内另附 [英文说明](../README.en.md)。只查看显示，不调整特性或任务，不为测试选择对话触发结果。

1. **加载与语言**：ToyBox 为 2.0.16，UMM 新模组 ID 为 `ToyBoxDisplayEnhancements`，需重新启用，版本为 0.4.0，显示 13 个补丁已安装。开启 ToyBox 的 `Bag of Tricks` → `Preview` → `Dialog Results` 与 `Dialog Conditions`。分别查看 ToyBox／游戏全中文、全英文及两种混合设置：标签跟随 ToyBox，官方名称和对白跟随游戏，UMM 状态随 ToyBox 切换。
2. **商人与招募**：中文显示“打开商人选择界面”和“进入自定义队友创建流程”；英文显示 `Open vendor selection` 和 `Begin custom companion creation`。招募要求显示利润因子门槛；“结果预览”／`Result preview` 与“后续可能涉及”／`Possible later results` 分层可读。
3. **剧情与对白**：单条件显示“剧情状态‘异端’未在运行”或 `Story state "Heresy" is not running`；多条件展开 AND／OR、单项与整体否定及嵌套缩进。对白引用区分本次对话与此前记录，检查英文长对白截断和分组换行；未知摘要仍可读。
4. **任务、信念与检定**：任务目标附所属任务名；信念名称、正负值与要求含义正确，出现检定使用游戏技能名称与难度。检查长文本换行、富文本和截断。
5. **八个特性**：按 [核查表](feature-evidence.md) 搜索八个 GUID 或内部名，检查名称和“汉化说明”／`Addon note`。分别使用中英文别名、内部名、GUID 搜索，开启／关闭描述搜索并比较结果；有效官方名称和描述优先，不点击增删或等级调整。
6. **技术详情**：在增强 UMM 面板切换详情，检查当前增强语言的说明、原摘要和内部标识，包括英文 Heresy 的别名来源；重启游戏后偏好仍保存。
7. **恢复**：切换 ToyBox 和游戏语言，重新查看预览和特性列表，名称、搜索、排序与描述同步更新。关闭增强或切换 ToyBox 为不支持的语言，确认原显示恢复；重新开启并切回中文或英文后增强恢复。
