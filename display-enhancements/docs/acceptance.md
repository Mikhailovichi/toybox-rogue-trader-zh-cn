## 用户界面验收

先关闭游戏并按中文版 README 将 0.2 覆盖到原独立 UMM 附加模组目录，不覆盖 `0ToyBox0`，不同时启用两份。保留 0.1 ZIP 用于回退。只查看界面，不增删特性、不修改任务状态、不选择对话来触发结果。

1. **加载**：UMM 附加模组面板显示 11 个补丁已安装，无“未启用增强”；ToyBox 简体中文界面开启。
2. **商人与招募截图**：商人条件展开原 `And[2]`／`And[3]`，组间与组内关系明确；结果为“打开商人选择界面”。招募显示“选择要求：利润因子达到招募自定义队友所需的门槛”与“后续可能涉及：进入自定义队友创建流程”。默认不再重复长警告和数字深度。
3. **异端与对白截图**：单条件显示“出现条件：剧情状态‘异端’未在运行”，不出现多层“全部满足／不满足”包装；`CueSeen` 尽量引用实际对白，而非只显示 `Cue_0019`。核对嵌套条件的换行缩进，长文不严重挤占选项区域。
4. **技术详情**：UMM 面板开启“显示技术详情”，刷新后中文摘要仍在，并附原摘要、相关内部标识和数字深度；关闭后恢复简洁版。重启游戏确认选择被保存，不为刷新提示推进剧情。
5. **已有对话覆盖**：查看原任务截图及 ToyBox 对话编辑页，确认三个官方目标名与所属任务名正确；信念正负值、点数门槛、技能难度及隐藏检定说明仍合理。未知摘要仍可辨认。
6. **特性回归**：八个条目的名称和“【汉化说明】”与 0.1 一致；官方描述优先，中文／内部名／GUID／描述搜索及显示内部名称仍可用。不点击移除或等级调整按钮。
7. **恢复**：关闭附加模组或切换 ToyBox 为英文，刷新列表并重新查看预览，确认恢复原摘要与原描述；重新开启后中文增强恢复。无需修改存档。
