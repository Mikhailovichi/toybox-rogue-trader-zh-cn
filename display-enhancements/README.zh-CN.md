# ToyBox 中文显示增强

面向《**战锤 40,000：行商浪人**》ToyBox 简体中文界面的可选附加模组：让已支持的对话预览更易理解，并为八个内部特性条目补充中文显示名称或说明。

本附加模组仅改变显示文本，不替换 ToyBox，不改变特性效果，不修改蓝图或存档，也不执行对话动作。

## 版本与依赖

- 附加模组：**0.2**（UMM 版本号 `0.2.0`），候选版。
- 需要原版 **ToyBox 1.7.34** 和 Unity Mod Manager；构建目标为游戏 **1.6.1.514**。
- ToyBox 界面须选择**简体中文（`zh-CN`）**；游戏语言也设为简体中文时，任务与目标名称会使用官方中文。
- **1.0 纯词表汉化包**为另一个独立安装包，可与本附加模组同时使用；本包不安装或覆盖该词表。

## 安装

1. 关闭游戏，先安装原版 ToyBox。
2. 将本包解压到游戏现有的 UMM 模组目录，保留 `ToyBoxChineseDisplayEnhancements` 文件夹。它与 `0ToyBox0` **并列，不放进 `0ToyBox0` 内**。Windows 默认路径为：

   ```text
   %USERPROFILE%\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\UnityModManager\
   ├── 0ToyBox0\
   └── ToyBoxChineseDisplayEnhancements\
       ├── Info.json
       ├── ToyBoxChineseDisplayEnhancements.dll
       ├── feature-aliases.zh-CN.json
       └── story-aliases.zh-CN.json
   ```

3. 启动游戏，在 UMM 中启用 **ToyBox Chinese Display Enhancements**。其面板会显示补丁是否成功加载。
4. 将 ToyBox 界面设为简体中文，按需开启 ToyBox 自身的“对话结果／条件预览”选项。本附加模组不会自动开启这些设置。
5. 默认使用简洁显示。需要查看原始摘要、内部标识及来源深度时，在本附加模组的 UMM 面板开启“显示技术详情”。选择会自动保存；已显示的对白请在下次刷新时检查，不必为此推进剧情。

## 主要改进

### 对话结果与条件

- 将已支持的任务目标动作显示为“开启目标”“完成目标”或“目标失败”，直接使用游戏的目标与所属任务名称，而非蓝图 ID。截图中的三个目标对应**返回着陆区域**、**与总督谈谈**和**探寻星站，寻找答案**。
- 使用“出现条件”“选择要求”区分选项何时出现、何时可选。单条件直接说明，多条件分行展示“以下条件都成立”或“满足以下任一组”，展开已支持的 AND／OR 分组并保留组合否定。
- 为指定 `Heresy` 剧情状态提供本包别名“异端”，例如“剧情状态‘异端’未在运行”；这不代表“从未触发异端剧情”，也不判断玩家的信念路线。未登记中文别名的状态保留内部名。
- 当前层使用**结果预览**，后续层使用**后续可能涉及**；来源深度只在技术详情中显示。不再为每个选项重复长篇说明：预览沿用 ToyBox 的分支收集规则，后续结果可能取决于分支与检定，不保证全部发生。
- 补充商人选择界面、自定义队友创建流程，以及招募所需利润因子门槛的中文说明。不显示未经求值的满足状态，也不将费用门槛写成确定扣费。
- 对“对白已显示过”条件，尽量引用官方对白前 40 个字符，区分本次对话与此前记录；缺少文本时保留原标识，不把“已显示”写成“已选择”。
- 信念变化显示中文信念名称与带正负号的数值；已支持的点数要求显示门槛，检定显示技能、难度及隐藏检定说明。游戏内 ToyBox 对话预览与 ToyBox 对话编辑页使用同一套格式。

### 内部特性条目

- 将三个 `SoulMark_Base` 条目标为**异端主义／自由主义／教条主义的内部记录**，不当作普通可选天赋介绍。
- 为基础角色特性组合、战斗后装填条目和自定义角色创建路径提供中文别名。补充说明位于原描述区域，带有**【汉化说明】**标记，不冒充官方描述。
- `IsPlayer_Feature` 和 `FeatProgressionTest` 保留内部名称，仅说明已确认的结构，不推测效果。已有的有效官方名称与描述始终优先。
- 名称搜索支持中文别名、原内部名及 GUID；开启“搜索描述”后可搜索补充说明。“显示内部名称”开启时，会在中文别名旁保留原标识，排序随显示名称调整。

## 关闭、移除与更新

在 UMM 中关闭本附加模组即可恢复原显示。切换开关或语言后刷新 ToyBox 列表；已打开的列表若保留旧排序，请关闭后重新打开。卸载时先关闭游戏，只移除 UMM 目录中的 `ToyBoxChineseDisplayEnhancements` 文件夹，不移除或替换 `0ToyBox0`。

更新 ToyBox 后，请改用兼容的附加模组版本。ToyBox 版本或补丁入口不匹配时，本包不会启用增强，并在 UMM 日志中记录原因；已有词表汉化不受影响。

从 0.1 升级时，关闭游戏，将 0.2 的文件覆盖到同一个 `ToyBoxChineseDisplayEnhancements` 文件夹，勿同时启用两份。需要回退时关闭游戏，用保留的 0.1 包覆盖本附加模组文件。0.2 的 `display-settings.json` 只保存显示偏好，不随安装包分发，也不会被更新覆盖；0.1 不读取此文件。

## 汉化范围与限制

0.2 仅覆盖上述对话类型与八个特性条目，不覆盖全部动作、条件或蓝图。不支持的类型、动态剧情状态求值、按信念阶级判断的要求，以及无法取得有效官方标题的任务／目标，保留 ToyBox 原摘要。因此部分英文内部标识会有意保留。

本包沿用 ToyBox 原有预览遍历和分支判断，不增加条件求值，也不预测全部可能结果。官方内容名称取决于游戏语言。特性说明用于辨认内部记录，不是增删这些条目的操作建议。0.2 候选版的实际排版仍待游戏界面确认。
